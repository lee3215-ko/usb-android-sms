# USB 안드로이드 문자 관리

휴대폰을 USB로 연결하면 컴퓨터에서 문자를 보고 보낼 수 있습니다.

## 다른 컴퓨터에 설치

1. [최신 릴리스](https://github.com/lee3215-ko/usb-android-sms/releases/latest)에서 `UsbSms-Windows-x64.zip`을 받습니다.
2. 압축을 풀고 `UsbSms.exe`를 실행합니다. Python은 필요 없습니다.
3. 휴대폰에서 개발자 옵션의 USB 디버깅을 켜고, 처음 한 번은 USB 설치 허용을 눌러 주세요.

대화 목록의 **스마트폰** 열에서 `열기`를 누르면 그 대화가 휴대폰 문자 앱에서 바로 열립니다. 이미지를 클릭하면 전체가 보이고, 마우스 휠로 확대하거나 축소할 수 있습니다.

프로그램을 켜 두면 새 버전이 나왔을 때 업데이트할지 물어봅니다. 대화 표시 설정은 업데이트 후에도 남습니다.

## 개발 컴퓨터에서 업데이트 배포

랜딩페이지 자동 배포와 같이, 버전 태그를 푸시하면 GitHub Actions가 설치 파일을 만들어 릴리스로 올립니다. 다른 컴퓨터의 프로그램이 다음 실행 때 그 릴리스를 받아 자동 업데이트합니다.

```powershell
.\scripts\publish.ps1 -Notes "변경 요약"
```
